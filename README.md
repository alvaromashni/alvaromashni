## 📌 Projetos em destaque

### 🟢 Tsugumi — SaaS de agendamento
Plataforma B2B para profissionais autônomos de saúde e bem-estar. Java 21 + Spring Boot + PostgreSQL + Flyway no backend, React + Vite + Tailwind no front, multi-tenancy e autenticação JWT. Publicado, com design system próprio feito no Figma e documentação de conformidade com a LGPD.

### 🟢 Nawat — totem de doações
Sistema de doações para templos religiosos, com integração a maquininhas e gateways de pagamento (PlugPag/PagBank, Pix). Deploy em VPS com Docker Compose.

### 🟢 Harvest Debt — roguelite de fazendinha
Jogo isométrico em Godot (GDScript) com breeding de animais, mutação de sementes e runs em dificuldade crescente. Em desenvolvimento, com lançamento planejado na Steam.

### 🟢 Bonsaai — hábitos gamificados
App de hábitos e evolução pessoal, com foco em experiência do usuário e visão de produto.

> Em todos eles, eu busco unir código, estrutura e visão de produto.
